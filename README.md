# Panchang & Festival Dates by Life Kundali (WordPress plugin)

Free daily panchang and city-accurate Hindu, Sikh and Jain festival dates for temple, gurdwara and community WordPress sites. Seven shortcodes and a sidebar widget.

This is the development mirror. To install, use the WordPress plugin directory or the zip from [lifekundali.com/developers.html](https://lifekundali.com/developers.html). The full description, FAQ and changelog are in [`readme.txt`](readme.txt).

## Shortcodes

```
[lk_panchang]  [lk_festivals n="6"]  [lk_gurdwara]  [lk_gurughar]
[lk_muhurta]   [lk_birth_chart]      [lk_matching]
```

Each takes `city="Surrey"` and `theme="dark"`. Defaults are under Settings → Panchang & Festivals.

## External service

Each shortcode inserts an iframe from `https://lifekundali.com/embed/`, run by ITERNITY RESEARCH CORP. (Brampton, Ontario). The plugin collects nothing about visitors and adds no link to your pages unless you turn on the credit link.
